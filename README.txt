LUMIÈRE BEAUTY STUDIO — WEBSITE DEMO

HOW TO OPEN
1. Unzip the downloaded project folder.
2. Double-click index.html to open it in Chrome, Edge, Firefox, or Safari.
3. An internet connection is needed for the Google Fonts and external photo URLs.

WHAT'S INCLUDED
- Responsive salon landing page
- Service cards, team profiles, about section, inspiration gallery
- Interactive 4-step appointment request flow
- Service-specific style choices, artist selection, date and time selection
- Demo request summary

IMPORTANT
This is a front-end prototype. It does NOT reserve a real appointment, verify staff availability,
send emails/SMS, accept payments, or save customer data. The dates/times shown are demo choices.
Before publishing for real clients, connect a backend and booking calendar, replace placeholder
address/contact details, verify prices and staff information, and use images you have permission to use.
